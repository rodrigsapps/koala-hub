## Funcoes

- **Auto Parry** — rebate a bola sozinho, com distancia e metodo configuraveis (Remote / Bindable / Key / Virtual)
- **Modo Spam** — troca de parry rapido
- **Auto Ability** — usa a habilidade quando a bola chega perto
- **ESP da bola** — Highlight + nome + linha ate voce
- **Player** — WalkSpeed, JumpPower, pulo infinito
- **Misc** — anti-AFK, FPS boost, rejoin, trocar de servidor

## Aviso

Auto parry usa os remotes do jogo. Abusar (spam, distancia absurda) chama atencao. Use com criterio.
